## 1. internal/cli/goat.go (NEW FILE)
Transcendence command group `vk` with three subcommands, layered on the
generated client (absolute-URL pattern, same as generated fi/info commands):

- `vk deals QUERY` — 0-100 "worth buying" score = discount% (0-20) + availability
  (0-25) + rating (0-30) + price band (0-25). Flags: --size, --min-discount,
  --min-score, --category, --price, --json.
- `vk categories [--query|--category] [--depth N] [--json]` — renders the
  category facet tree (with hit counts) from the search `included` block.
- `vk watch add|list|remove|check` — price/stock change tracking; state JSON
  persisted to the CLI data dir (`watch.json`). check prints price deltas
  (▼/▲) and stock flips.

Requires `rootCmd.AddCommand(newVkCmd(flags))` in internal/cli/root.go
(hand-edit; see below).

## 4. bin/vk-sale.py
Deep-discount sweeper: pages `filter[has_discount]=true` per category,
computes real discount % (original vs current), filters >= --min-disc
(default 50). Default categories: information_technology, pc_gaming,
computer_peripherals, headsets_for_gaming. Prints table with live stock;
--json for machine output.
